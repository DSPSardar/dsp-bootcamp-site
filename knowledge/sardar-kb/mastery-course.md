# DSP AI Agent Mastery — Zero to Master: the course, module by module

Source: src/content/mastery/course.json (course version 0.9.0) and the public curriculum at https://www.digitalservicesprogram.com/mastery/curriculum. Prices and support terms are in mastery-offer.md.

## The course in one paragraph

DSP AI Agent Mastery is a self-paced AI agent course for complete beginners, taught in an Urdu–English mix by Sardar Ghaffar. Across 16 modules the student builds one working AI Employee, a café ordering agent, from an empty folder to a live URL using Claude Code, then builds their own agent as a capstone. Lectures are recorded, access is lifetime, and support runs for 12 months in the DSP group. The one formula behind the whole program: Agent = Claude + Job Description + Tools + Loop.

## How the course works

- Start here: three welcome videos open the dashboard. W01 Welcome and Orientation, W02 Inside DSP (a walkthrough of the student dashboard), and W03 How to do this course.
- Rhythm: watch the module's chaptered lectures, build that module's project with its template and copy-paste prompts, share the screenshot or URL in the DSP group, mark the module complete, and the next one opens.
- Progression: modules open in order as the student marks them complete. No quizzes, no grading. Badges are awarded at each phase.
- Always-open modules: Module 15 (Selling AI Solutions) and Module 16 (AI Search Dominance Engine) are open from day one with no prerequisites, so a student can start selling or building an SEO page before finishing the build thread. Every other module unlocks when the previous one is marked complete, because each build extends the last.
- Materials: every module ships its slides and downloadable templates; the Resource Vault holds bonus lectures, 100+ prompts and 25 starter Job Descriptions.
- The guided project: the café AI Employee. It starts as an empty folder in Module 4, becomes a four-page website, then an agent that takes orders, remembers customers, emails the kitchen and writes to Google Sheets through MCP, built with Claude Code, versioned on GitHub, deployed on Vercel, and by Module 14 serving two cafés from one codebase.

## Five phases

- Phase 0, Zero — Foundations (Modules 1–3): you can explain what an agent is and write a Job Description that works.
- Phase 1, Builder (Modules 4–6): you can build and version software by describing it. Badge: Builder.
- Phase 2, Agent Engineer (Modules 7–10): your website becomes an agent that acts, remembers and connects. Badge: Agent Engineer.
- Phase 3, Production (Modules 11–13): your agent is tested, hardened and live on the internet. Badge: Production-Ready.
- Phase 4, Seller (Modules 14–16 plus the capstone): you can turn one agent into a business and sell it. Badges: AI Solutions Seller, AI Search Dominator, then Master.

## The 16 modules

### M01 — AI Foundations (Phase 0)
Outcome: explain what an LLM and an agent are, what each can't do, and pick one idea worth building using the Agent Idea Filter.
Lessons, in order: What is Artificial Intelligence?; What is Generative AI?; What are AI Agents and how do they work?; From Generative AI to Agentic AI; Lecture 1, AI and AI Agents: The Big Picture; Lecture 2, The Next Level of AI: Fundamentals, Agents, Autonomy.
You build: Pick Your Agent. Five ideas through the Idea Filter, one chosen with a clear user and success condition.
Templates: Agent Idea Filter worksheet, DSP AI Glossary, AI in One Page cheat sheet.

### M02 — Prompting & Context Engineering (Phase 0)
Outcome: write a production-grade Job Description using the 7-Part JD (Role, Goal, Audience, Tone, Steps, Rules, Examples) and explain why context decides whether an agent works.
Lessons: How to Talk to AI; Tokens and Context Windows: Memory and Cost; What is a Prompt and Prompt Engineering?; Lecture 1, Prompt Engineering is not Enough: Context Engineering; Lecture 2, Context Engineering in Practice; Lecture 3, 4 Ways AI Agents Fail and How to Fix Them.
You build: Write the JD. Your 7-Part JD v2 with three real test inputs and a note on what you changed.
Templates: 7-Part JD template, 25 starter JDs, prompt iteration log, context failure-modes checklist.

### M03 — Claude · ChatGPT · Gemini (Phase 0)
Outcome: set up Claude, Console, Claude Code, GitHub and Vercel; know when to reach for each tool; understand tokens and cost. This module also walks through Claude Academy, Anthropic's free training, so the student earns the Claude 101, Claude Code 101 and Introduction to Claude Cowork badges.
Lessons: Claude Step by Step: Beginner's Guide; From ChatGPT to GPT-6 Astra; How Codex Works; Lecture 1, Claude Masterclass: Setup, New Features and Workflows; Lecture 2, Claude Chat, Cowork and Claude Code; Lecture 3, Google AI Studio and Gemini.

Templates: setup checklist (Mac and Windows), tool comparison matrix, cost and token table, Windows/Cowork troubleshooting.

### M04 — Vibe Coding (Phase 1)

## Capstone and certificate rules

- The capstone is the student's own original agent for a real use case, not the café AI Employee, built with the same method.
- Deliverables: a live HTTPS URL, a public GitHub repo with 20+ commits, a 3-minute demo video and a 1-page proposal. The brief and rubric are in the dashboard (Capstone Brief and Rubric).
- Review: by the DSP team. A student can resubmit at any time.
- Passing the capstone earns the Master badge and the DSP Master certificate. Every DSP certificate has a public verification page showing the capstone URL and repo behind it, so an employer or client can open it and see the agent working. Featured capstones earn Master with Distinction.
- Milestone badges along the way: Builder (after M06), Agent Engineer (after M10), Production-Ready (after M13), AI Solutions Seller (after M15), AI Search Dominator (after M16), Master (capstone).
- Separately, Module 3 takes the student through Claude Academy, Anthropic's free training, so they finish holding three Anthropic-issued badges with their own name on them: Claude 101, Claude Code 101 and Introduction to Claude Cowork. Those are issued by Anthropic, not by DSP. None of these is a university accreditation.
