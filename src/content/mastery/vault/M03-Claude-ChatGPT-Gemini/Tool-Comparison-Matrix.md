# Tool Comparison Matrix — Claude vs ChatGPT vs Gemini
Use this to decide which tool fits a task. This course is built on Claude, but knowing when to reach for the others makes you more useful to clients.

| | Claude | ChatGPT | Gemini / AI Studio |
|---|---|---|---|
| Best for | Long documents, careful reasoning, coding with Claude Code, agentic tool-use | Broad general use, image generation, voice mode | Very large context, Google Workspace integration, free tier for prototyping |
| Coding | Claude Code — reads/writes/runs your project files directly | Code Interpreter — sandboxed, less integrated with your own repo | AI Studio — good for prototyping with the API, less mature agent tooling |
| Context window | Large — good for feeding in full documents or codebases | Large on paid tiers | Very large — best for huge documents |
| Agent/tool-use | Native strength — Projects, MCP connectors, Claude Code | Custom GPTs, function calling | Function calling, improving fast |
| Cost for this course | Primary tool — budget ~$5-10 total with token-saving workflow | Optional comparison only | Free tier is enough for the M03 comparison exercise |
| When to recommend to a client | Default choice for agent builds in this course | Client already has ChatGPT Plus and wants quick content tasks | Client is deep in Google Workspace (Sheets/Docs/Gmail) |

## The exercise for this module
1. Do a real task in Claude (write your M02 Job Description, test it).
2. Do the exact same task in ChatGPT or Gemini.
3. Write 5 lines: which handled it better, and why — accuracy, format, speed, or cost.

There's no wrong answer here — the point is building the judgment to pick the right tool for a client's situation, not just defaulting to whatever you know first.
