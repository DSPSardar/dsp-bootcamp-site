# Cost & Token Table — what this course actually costs to run
Rough guide so you're not surprised. Prices are approximate and change — check console.anthropic.com for current rates.

## What uses tokens
- Every message you send and every response you get, in tokens (roughly ¾ of a word each)
- Claude Code sessions use tokens for its own reasoning too — long sessions cost more
- A knowledge base (RAG) adds tokens when the agent retrieves and reads from it

## Rough budget for this whole course
| Activity | Approx. cost |
|---|---|
| M01-M03 (foundations, JD writing, tool comparisons) | under $1 |
| M04-M06 (vibe coding the website) | $1-3 |
| M07-M10 (agent, APIs, RAG, MCP) | $2-4 |
| M11-M13 (testing, security, deployment) | $1-2 |
| Capstone (your own agent) | $1-3 |
| **Total for the whole program** | **roughly $6-13** |

## How to keep costs down
- Use `/compact` in Claude Code to summarize old context instead of carrying it all forward
- Use `/clear` when starting a genuinely new task, not mid-build
- Don't paste entire large documents into chat when only a section is relevant
- Test your agent's JD with a few inputs, not fifty, before you're confident in the direction

## For when you're selling to clients (M15)
When you price a client project, include their expected ongoing token cost as a small monthly line item — most client agents run $2-15/month depending on volume. This is a real number you can quote confidently, not a guess.
