# Automation Blueprints — 5 Industries
Starting points for adapting your AI Employee pattern to other business types.

## 1. Café / Restaurant (this course's core project)
Trigger: customer message → Agent: takes order, confirms, sends to kitchen → Automation: order log + owner notification

## 2. Clinic / Salon (booking-based)
Trigger: enquiry → Agent: checks availability, books, confirms → Automation: calendar entry + reminder message before appointment

## 3. Real Estate
Trigger: property enquiry → Agent: answers from real listing data, books a viewing → Automation: lead logged in a sheet/CRM, agent notified

## 4. Tutoring / Education
Trigger: student/parent question → Agent: answers from real class info, or books a trial session → Automation: lead captured, follow-up scheduled

## 5. Travel Agency
Trigger: enquiry → Agent: gathers preferences, presents options, books → Automation: booking confirmation sent, payment reminder scheduled

## The pattern behind all 5
Every one of these follows: **Trigger → Agent (JD + Tools + Loop) → Automation (what happens after the conversation ends).** Once you can build one, adapting to a new industry is mostly changing the knowledge base and the specific tools, not the underlying architecture.
