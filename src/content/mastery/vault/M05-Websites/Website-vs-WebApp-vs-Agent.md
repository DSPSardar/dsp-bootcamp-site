# Website vs Web App vs AI Agent — what's the difference?
Useful when a client asks "can't you just build me a website" and doesn't yet see why they need more.

**Website** — presents information, collects input through simple forms. Nobody is "talking" to it — it just shows pages. Good for: menus, portfolios, basic contact forms.

**Web App** — has logic and stored data: user accounts, a database, dynamic content that changes per user. Still not "intelligent" — it follows fixed rules a developer wrote.

**AI Agent** — has a Job Description, can hold a conversation, make judgment calls within its rules, and take actions through Tools. It can handle a customer saying "actually can I change my order" — a plain website form cannot.

## Why this course builds all three, in order
A website (M05) is the foundation. Turning it into a web app with real logic happens as you add APIs (M08). Turning it into an agent (M07) is what makes it feel intelligent — able to hold a conversation, not just collect a form. Most client projects need all three layers working together.
