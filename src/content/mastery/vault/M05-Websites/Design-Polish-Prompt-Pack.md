# Design Polish Prompt Pack
Use these once the structure and content are in place, to make it look intentional rather than default.

- "This looks generic — give it a more distinctive visual identity: suggest a font pairing and colour palette that fits a [mood: warm/modern/premium/playful] brand, and apply it."
- "Improve the spacing and visual hierarchy on this page — right now everything feels the same size and weight."
- "Add subtle hover states to the buttons and links so the page feels interactive."
- "Check color contrast for accessibility — make sure text is readable against its background."
- "Add a favicon and a page title that matches the business name."
- "Make the call-to-action button visually stand out more than everything else on the page."

## Reminder
Don't polish before the structure is right — fix the bones first (from the 10 landing page prompts), then use this pack.
