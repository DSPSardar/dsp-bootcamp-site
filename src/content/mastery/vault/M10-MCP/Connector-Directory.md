# MCP Connector Directory (starting points)
Common connectors useful for the kinds of agents this course builds. Availability and exact names change as the ecosystem grows — check docs.claude.com/mcp for the current list.

| Connector | Useful for |
|---|---|
| Google Sheets | Order logs, lead lists, simple databases |
| Google Calendar | Booking agents, appointment scheduling |
| Gmail | Sending confirmations, reading enquiries |
| Google Drive | Storing and retrieving documents/knowledge base files |
| Custom MCP server | Anything specific to a client's own system (their own database, their own booking tool) — built following the MCP-Builder Prompt Template below |
