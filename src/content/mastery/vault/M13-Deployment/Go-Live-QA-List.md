# Go-Live QA List
Final check before calling something done.

- [ ] Load the live URL on your phone — does it look right?
- [ ] Complete one full interaction end to end (a full order, a full booking) on the live site
- [ ] Check page source (right-click → View Page Source) — confirm no API key is visible
- [ ] Try an intentionally wrong input — confirm it fails gracefully, not with a blank screen or crash
- [ ] Check the response time feels reasonable, not sluggish
- [ ] Send the URL to one other person and watch them use it without your guidance — do they get stuck anywhere?
