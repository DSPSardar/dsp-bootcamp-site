# AI Search Dominance Engine — Pipeline Checklist
Run this top to bottom for every target query. One query in, one deployed page out. Tick each stage before moving on — the order matters.

## Stage 0 — Setup
- Create the project folder and open it in Claude Code
- Write the target query, the site it lives on, and the business goal at the top of your prompt

## Stage 1 — Research
1. Query fan-out — list every related question, sub-intent and follow-up a searcher (or an AI assistant) would ask
2. SERP intelligence — what is ranking now, what format it uses, what it leaves out
3. Intent — informational, commercial, transactional, or mixed; decide the page type from this
4. Competitor gap — what the top results all miss, or explain badly
5. Information gain — the facts, data, examples or experience only you can add

## Stage 2 — Architecture
6. Entity / semantic map — the people, products, places and concepts the page must name and connect
7. Content architecture — headings, sections, FAQs and the answer-first block at the top

## Stage 3 — Build
8. Build the page (describe it in English, Claude Code writes it)
9. Technical SEO — title, meta, canonical, speed, mobile, crawlability
10. Internal links — link in from existing pages and out to the pages that support this one
11. Structured data — the schema types the page qualifies for (Article, FAQ, Organization, Person, Product…)

## Stage 4 — Ship
12. QA — every fact checked, every link works, nothing thin, nothing duplicated
13. SEO Win Score — score the page against the checklist before it goes live; fix anything below target
14. Deploy — push to production, confirm the live URL, request indexing
15. Measure — impressions, clicks, and whether ChatGPT / Gemini / Perplexity / Google AI mention the page for the query

## Hand-in for the build project
- Live URL
- Your target query and its fan-out list
- Your SEO Win Score before and after fixes
