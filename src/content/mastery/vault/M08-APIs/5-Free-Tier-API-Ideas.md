# 5 Free-Tier External APIs to Practice With
Pick one for your M08 assignment. All have free tiers sufficient for this course.

1. **Resend** (resend.com) — send transactional emails, generous free tier, simple API
2. **Google Sheets API** — free with a Google account, good for a simple order/lead log
3. **Google Calendar API** — free, good for booking-type agents
4. **OpenWeatherMap** — free tier, good practice for a simple "fetch external data" tool
5. **WhatsApp Business API** (via a provider like Twilio's sandbox, or Meta's own free tier for testing) — good practice for the notification pattern used in real client work
