# The Agent Idea Filter
Use this to test any "I could automate this" idea before you build it. Score each idea 1–5 on every question. An idea scoring 4-5 average is worth building.

## The 5 Questions

**1. Is it repeatable?**
Does this task happen more than once — daily, weekly, every time a customer does X? A one-off task is not worth automating.
- 1 = happens once · 5 = happens every day

**2. Is the input and output clear?**
Can you describe, in one sentence, what goes IN (a message, a form, a question) and what comes OUT (an answer, a booking, an order)? If you can't describe it in one sentence, it's not ready for an agent yet — it's still two or three ideas mixed together.
- 1 = vague, "help with marketing" · 5 = "customer sends order → agent confirms and emails kitchen"

**3. Does it save real time or make real money?**
Would a real person be relieved if this stopped landing on their desk? Would a business pay for it, or is it solving a problem nobody has?
- 1 = nice to have · 5 = someone is doing this manually for hours every week right now

**4. Is it safe to automate?**
Nothing here requires a human judgment call that carries legal, medical, financial or safety risk if the AI gets it wrong. (Reminders, bookings, FAQs = safe. Medical diagnosis, contracts, large financial decisions = not agent-only.)
- 1 = high-stakes judgment call · 5 = low-risk, reversible if wrong

**5. Is it doable with Claude + Tools?**
Can you imagine the tools it would need — send an email, check a calendar, read a spreadsheet, look up a menu? If the tools exist or are buildable, it's doable in this course.
- 1 = needs something exotic (robotics, real-time video) · 5 = text in, tool calls, text out

## Examples that pass the filter
- A café agent that takes WhatsApp orders and confirms totals (this course's project)
- A tutor's agent that answers "when's my next class" and reschedules from a calendar
- A clinic's agent that qualifies a lead, books a slot, sends a reminder
- A freelancer's agent that drafts a project proposal from a client's brief

## Examples that don't (yet)
- "An agent that manages my whole business" — not one clear input/output, it's ten ideas
- "An agent that gives legal advice" — safety score too low for this course
- "An agent that only helps once, for one event" — not repeatable enough to be worth building
