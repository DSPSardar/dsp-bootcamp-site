# GitHub Setup Checklist
- [ ] Account created at github.com
- [ ] Git installed locally (check with `git --version` in your terminal — Mac usually has it already)
- [ ] Git configured with your name and email:
  ```
  git config --global user.name "Your Name"
  git config --global user.email "you@email.com"
  ```
- [ ] New repository created on GitHub (Public, so your capstone can be reviewed)
- [ ] Repository connected to your local project:
  ```
  git remote add origin https://github.com/yourusername/your-repo.git
  git push -u origin main
  ```
- [ ] Confirmed: refreshing the GitHub page shows your files
