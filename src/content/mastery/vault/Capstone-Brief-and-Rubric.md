# Capstone Brief — Your Own AI Solution
The final project. Build, test, secure, deploy and pitch an original agent — not the AI Employee café project. This is what earns the certificate.

## Requirements
1. **Pick your own use case** — from your M01 Agent Idea Filter, or a new idea, in a domain different from café ordering.
2. **Build it fully** through the same stages as the course: Job Description → website/interface → agent with tools → knowledge/memory if relevant → tested → secured → deployed live.
3. **Deliver:**
   - Live HTTPS URL (the agent actually works when opened)
   - Public GitHub repo, at least 20 meaningful commits
   - Completed 10-Question Test Sheet and Security Checklist for this agent
   - A 3-minute demo video: the problem, the agent in action, the result
   - A 1-page proposal, as if pitching this to a real client (use the Proposal Template)

## What makes a strong capstone
- It's genuinely original — not a reskin of the café project with different words
- All four parts of the formula (Claude + JD + Tools + Loop) are clearly present and documented
- It handles at least one real edge case gracefully, not just the happy path
- The demo video shows it actually working, not just described

## Review process
Submitted work is reviewed by the DSP team. If something needs fixing, you'll get specific feedback and can resubmit any time — there's no penalty for a first draft not being perfect. Strong capstones may be featured in the student showcase.

## Certificate
Completing all 15 modules plus an approved capstone earns the DSP AI Agent Mastery — Master certificate, with a public verification page.
